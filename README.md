One sharp, funny loading-screen tip for stressed developers and AI coding agents. Written for make.fun's "Loading Screen Gold: A Tip in 200 Characters" bounty.

## The line

> Tip: if the build takes longer than your patience, it is not stuck — it is just compiling your regrets one dependency at a time.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this line

It works because it is a real tip in form — "Tip:" and a reassurance that the build is not stuck — and the reassurance is a roast: the build is slow because it is compiling the developer's own regrets, one dependency at a time. Anyone who has watched a progress bar crawl through a dependency tree they chose themselves recognises the feeling instantly, mid-build, which is exactly when a loading-screen tip lands. The joke is economical: no word in it could be cut without losing either the tip or the punch.
